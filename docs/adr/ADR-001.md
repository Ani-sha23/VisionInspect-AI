# ADR-001: One segmentation model instead of three task-specific models

**Status:** Accepted
**Date:** 2026-09

## Context

The system must do three things: localise defect regions, label each region with
one of four Severstal classes, and report which classes an image contains. The
obvious design is three components — a detector, a classifier, and a segmenter —
each trained separately.

Available compute is a single free-tier GPU session, and the three heads would
have to be trained, tuned, and evaluated independently.

## Decision

Train **one multi-label segmentation network** with four sigmoid output channels,
and derive the other two outputs from its masks:

- **Localisation** — connected-component analysis on the thresholded masks gives
  bounding boxes and instance counts.
- **Per-region class** — the channel a component came from is its class.
- **Image-level labels** — the set of channels with at least one surviving
  component.

Sigmoid rather than softmax, because Severstal images can carry more than one
defect class at once; the classes are not mutually exclusive.

## Consequences

**Positive**

- One training run instead of three, within the available compute budget.
- Classification and localisation cannot disagree: a class is reported present
  exactly when a region of it survived thresholding.
- Masks are strictly more informative than boxes — area feeds directly into the
  severity score, which boxes could only approximate.
- A new backend (a pretrained encoder, say) slots in behind the same
  `masks_to_defects` conversion with no downstream changes.

**Negative**

- Two overlapping defects of the same class merge into one component and are
  counted once. A dedicated instance-segmentation model would separate them.
- Instance count is sensitive to `mask_threshold` and `min_component_area`; both
  are configuration, and both affect the severity score's count term.
- Thin, broken defects can fragment into several components and be over-counted.

## Alternatives considered

| Alternative | Why rejected |
|---|---|
| Separate detector (YOLO/Faster R-CNN) + classifier + segmenter | Three training budgets; needs box annotations Severstal does not provide (they would have to be derived from masks anyway) |
| Classification-only CNN | Gives no location and no area, so no severity score and nothing to show an inspector |
| Softmax multi-class segmentation | Forbids multi-class images, which exist in the dataset |
| Classical CV only | No class labels; retained as a fallback backend rather than the primary method |

## Verification

`tests/test_detector.py::test_masks_to_defects_assigns_class_from_channel` pins the
channel→class mapping; `test_masks_to_defects_separates_two_blobs` confirms
separate components become separate instances; `test_masks_to_defects_drops_small_components`
confirms the noise filter.
