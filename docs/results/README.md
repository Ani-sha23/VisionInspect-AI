# Measured results

Files in this directory are **generated by the code**, not written by hand:

| File | Produced by |
|---|---|
| `dataset_stats.md` | `visioninspect inspect-data` |
| `severity_calibration.md` | `visioninspect calibrate` |
| `evaluation.md` / `evaluation.json` | `visioninspect evaluate` |

The directory ships empty on purpose. Anything quoted in the project report must
come from a file here that your own run produced — if a command has not been run
yet, the corresponding claim does not belong in the report.
